Intercontinental Zoe — MCP server

This is an API-only MCP (Model Context Protocol) server for the travel YouTuber Intercontinental Zoe. There is no user-facing website here — all requests are handled by the serverless function at api/[...path].ts.

Useful endpoints:

  • GET /healthz — liveness probe
  • GET /openapi.json — OpenAPI 3.1 spec for ChatGPT Custom GPT Actions
  • POST /mcp — MCP Streamable HTTP transport (Bearer auth)
  • POST /actions/:tool — REST mirror of every MCP tool (Bearer auth)

See the repository README for deployment and client setup instructions.
